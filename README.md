# R.A.Z Intelligence Challenge 🌸✨

Website tes kecerdasan dan wawasan interaktif personal untuk **Raz**, dikembangkan dengan desain bernuansa pastel lavender, soft pink, dan aksen ungu neon bertema iOS modern dan anime estetik.

---

## 🌟 Fitur Utama

1. **Desain Visual Feminin & Premium**:
   - Palet warna: Pastel Lavender, Soft Pink, Putih, dan Ungu Neon.
   - Efek Glassmorphism, Rounded Corners, dan Glowing Shadows.
   - Ilustrasi karakter anime perempuan konsisten dengan 6 ekspresi:
     - *Welcome* (Wink & headphone bercahaya)
     - *Thinking* (Reflektif dengan ide/bohlam)
     - *Confused* (Muka bingung dengan ornamen "??")
     - *Happy* (Senyum ceria dengan mahkota/pita)
     - *Sad* (Cemberut dengan tetesan air mata)
     - *Celebration* (Mahkota emas dan letupan konfeti bintang)
   - Dukungan penuh **Mode Gelap (Dark Mode)** dan **Mode Terang (Light Mode)**.

2. **Opening Page Menarik**:
   - Logo Glowing Neon Brain dengan orbit memutar.
   - Partikel melayang: bintang, hati, dan sparkles bercahaya.
   - Ringkasan metrik: 30 Soal, 6 Kategori, 60 Menit waktu tes.
   - Deteksi sesi tersimpan: Opsi melanjutkan pengerjaan jika sempat keluar/refresh.

3. **Sistem 30 Soal Berbobot (Menengah - Sulit)**:
   - **Matematika Sehari-hari**: 6 Soal (Panen cabai, diskon bertingkat, kecepatan rata-rata harmonik, perbandingan pekerja, luas keramik, bunga majemuk).
   - **Ekonomi & Keuangan**: 5 Soal (Margin keuntungan modal, biaya peluang / opportunity cost, Break-Even Point kafe, daya beli inflasi 2 tahun, elastisitas harga).
   - **Logika & Penalaran**: 7 Soal (Silogisme formal, pola deret angka eksponensial, posisi duduk meja bundar, teka-teki kejujuran suku pulau, modus tollens, deret alfabet melingkar, penimbangan koin neraca).
   - **Ilmu Pengetahuan Alam (IPA)**: 5 Soal (Hamburan Rayleigh langit biru & senja, fermentasi asam laktat & siklus NAD+, pengenceran asam pH, pendinginan evaporatif pakaian basah, refraksi sedotan air).
   - **Pengetahuan Islam**: 4 Soal (Hukum shalat berjamaah Mazhab Syafi'i, Bayt al-Hikmah Baghdad, definisi Ihsan Hadits Jibril, kodifikasi Mushaf Utsmani).
   - **Pengetahuan Kristen**: 3 Soal (Kitab Pentateukh / Taurat Musa, Pertobatan Saulus / Rasul Paulus di Damaskus, 9 Buah-buah Roh Galatia).

4. **Animasi Unik Tiap Kategori**:
   - Visual bertema dinamis untuk Matematika, Ekonomi, Logika (Kucing berkacamata keren), IPA (Atom berputar & awan), Agama Islam (Kubah masjid & bulan sabit), dan Pengetahuan Kristen (Kaca patri & sinar fajar).

5. **Fitur Pengerjaan Ramah Pengguna**:
   - Progress bar dinamis 1–30.
   - Timer hitung mundur 60 menit dengan peringatan saat waktu kritis.
   - Drawer / Palet Soal interaktif untuk lompat langsung ke nomor tertentu.
   - Tombol "Tandai / Bookmark" untuk soal yang masih ragu.
   - Auto-save ke `localStorage` (jawaban aman saat halaman dimuat ulang).
   - Dialog konfirmasi sebelum submit akhir.

6. **Halaman Hasil & Analisis Performa**:
   - Counter nilai animasi 0–100 & estimasi skor IQ.
   - Statistik jawaban benar, salah, dan persentase akurasi.
   - Grafik performa untuk masing-masing dari 6 kategori.
   - Kritik cerdas dan menghibur berdasarkan bracket nilai:
     - `0–20`: Kritik gaul pedas lucu mode hemat baterai.
     - `21–50`: Kritik pedas tapi membangun.
     - `51–79`: Motivasi dan panduan asah logika.
     - `80–99`: Pujian untuk otak encer.
     - `100`: Tampilan perayaan pemenang sempurna dengan konfeti emas & mahkota!
   - Modal Pembahasan Soal lengkap untuk mereview seluruh 30 jawaban beserta penjelasan ilmiahnya.

7. **Surat Evaluasi untuk Raz & Integrasi WhatsApp**:
   - Animasi amplop interaktif yang terbuka menjadi kertas surat pastel estetik.
   - Rangkuman skor, predikat, dan evaluasi.
   - **Form Catatan Tambahan Wajib Diisi** sebelum tombol kirim aktif.
   - Tombol **Kirim ke WhatsApp**: Membuka WhatsApp dengan pesan yang telah tersusun rapi untuk dikirim ke nomor pemilik website.
   - Nomor WhatsApp pemilik dapat diubah sewaktu-waktu langsung dari menu navigasi atas.

---

## 🚀 Menjalankan Project

```bash
# Install dependencies
npm install

# Jalankan server development
npm run dev
```

Buka browser di `http://localhost:3000` untuk mulai mencoba tes!
